## Overview

Haunted Inbox is a Halloween-themed cybersecurity awareness game that teaches students how to identify phishing attacks, scams, and other online threats.

Stark State College's networks have been cursed by cyber monsters. Players join the **Cyber Defense Academy** and travel through five haunted regions, spotting real-world threats, defeating a boss at the end of each region, and bringing the campus infection level from 100% down to 0% to save the campus.

## Features

- **Five haunted regions** covering phishing, social engineering, malware, smishing, and advanced threats
- **30 interactive challenges** in six formats: Safe-or-Suspicious verdicts, red-flag hunts, link X-rays, chat conversations, file and permission triage, and real-life scenarios
- **Five boss battles** where players defeat monsters by naming the threat indicators in their attacks, ending with an incident-response showdown
- **Real-time feedback** after every answer: highlighted red flags, a lesson, and a real-world tip
- **Campus Story Mode** with cinematic scenes, dialogue, character portraits, and a campus infection meter
- **AI Threat Analyzer:** paste any email or text and get a 0–100 threat score with an explanation. It's rule-based, so it runs entirely in the browser
- **XP, six ranks, and 24 achievements**, from *Cyber Rookie* to *Campus Defender*
- **Difficulty that builds region by region**, with HP, critical hits, and multi-phase bosses
- **Halloween-themed experience** with original art and an original soundtrack that intensifies during boss battles
- **Judge Mode** to unlock every region and skip straight to any boss for quick demos

## How to Play

1. Click **Begin** and watch the opening story (or skip it).
2. Pick an unlocked region on the world map.
3. Complete six challenges. Check senders, links, attachments, and what each message is really asking for.
4. Defeat the region's boss by playing indicator cards that match the threats in its attacks.
5. Earn XP, rank up, unlock achievements, and save the campus.

Progress is saved in your browser. You can reset it from the title screen.

## Built With

- HTML
- CSS
- JavaScript

There are no frameworks, libraries, or build tools. The entire game is a single `index.html` file. The music and sound effects are generated live with the Web Audio API, and all artwork is original SVG.

## Running It Locally

Download `index.html` and open it in any modern browser. That's it.
